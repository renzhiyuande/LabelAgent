# 系统管理员指南

## 概述

系统管理员（Admin）负责 LabelHub 平台的系统级配置与运维管理。

**操作指南**：如需面向 Admin 的使用说明与分步操作指引，请参见[系统管理员操作指南](../../business/admin/overview)。

### 核心职责

- **用户管理**：平台用户账号的创建、编辑、权限分配
- **角色权限**：角色定义与权限点配置
- **系统配置**：LLM 提供商、字典、菜单、维度包等配置
- **运维管理**：审计日志、异步任务、定时任务监控

### 功能入口

| 页面 | 路由 | 说明 |
|------|------|------|
| 用户管理 | `/system/users` | 用户账号管理 |
| 角色管理 | `/system/roles` | 角色与权限管理 |
| 权限管理 | `/system/permissions` | 系统权限点管理 |
| 菜单管理 | `/system/menus` | 侧边栏菜单配置 |
| 字典配置 | `/system/dicts` | 系统字典管理 |
| LLM 提供商 | `/system/llm-providers` | AI 模型配置 |
| 审计日志 | `/system/audit` | 操作审计日志 |
| 异步任务 | `/system/async` | 异步任务监控 |
