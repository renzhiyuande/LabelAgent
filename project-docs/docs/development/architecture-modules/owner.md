# 任务负责人指南

## 概述

任务负责人（Owner）是 LabelHub 平台的核心管理角色，负责标注任务的**全生命周期管理**。

**操作指南**：如需面向 Owner 的使用说明与分步操作指引，请参见[任务负责人操作指南](../../business/owner/overview)。

### 核心职责

- **模板搭建**：使用可视化编辑器构建标注表单 Schema
- **创建任务**：定义标注任务，选择模板，导入数据
- **任务分配**：通过市场开放或指定分配方式分发任务
- **数据验收**：验收已完成的标注数据
- **数据导出**：导出标注结果用于下游训练或评测
- **奖励结算**：管理标注员的标注报酬

### 功能入口

| 页面 | 路由 | 说明 |
|------|------|------|
| 任务管理 | `/owner/tasks` | 任务全生命周期管理 |
| 创建任务 | `/owner/tasks/create` | 新建标注任务 |
| 模板市场 | `/owner/template-market` | 浏览选用标注模板 |
| 任务分配 | `/owner/assignments` | 标注任务分配管理 |
| 数据验收 | `/owner/acceptances` | 标注数据验收 |
| 数据导出 | `/owner/exports` | 标注结果导出 |
| 奖励结算 | `/owner/settlements` | 标注报酬结算 |
