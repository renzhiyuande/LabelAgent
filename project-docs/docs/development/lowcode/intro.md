# LabelHub 低代码引擎

**Schema 驱动的管理后台快速开发框架**

LabelHub 低代码引擎是一套**声明式资源配置系统**——用一份 TypeScript 配置（[`ResourceMeta`](./guide/resource-meta)）描述一个完整的业务资源页面，引擎自动渲染出查询栏、数据表格、创建/编辑表单、详情抽屉、操作按钮和侧面板，无需手写 CRUD 页面代码。

## 核心思想

```
写一份 [ResourceMeta](./guide/resource-meta) 配置
    ↓
引擎自动渲染完整的 CRUD 交互界面
    ↓
专注业务逻辑，减少重复代码
```

## 能力概览

| 能力 | 说明 |
|------|------|
| **查询栏** | 多字段筛选、关键字搜索、日期范围、折叠/展开（详见[查询栏](./guide/filters)） |
| **数据表格** | 排序、分页、列定制、行操作、批量操作、选择器模式（详见[数据表格](./guide/table)） |
| **表单** | 远程加载选项、依赖联动、条件显隐、动态子表单、远程 Schema 懒加载（详见[表单](./guide/form)） |
| **详情抽屉** | 分段展示、Tab 切换、JSON/富文本/文件/图片展示（详见[详情抽屉](./guide/detail)） |
| **操作按钮** | 直接请求、确认弹窗、弹窗表单、分配、工作流、侧面板（详见[操作按钮](./guide/actions)） |
| **页面布局** | 标准列表、卡片式、树形+表格（详见[页面布局](./guide/page-layouts)） |
| **权限控制** | 页面级、字段级、列级、操作级权限（详见[权限体系](./guide/permissions)） |
| **LLM 集成** | AI 辅助标注（Chat/Agent 模式，详见[高级功能](./guide/advanced)） |
| **类型安全** | 所有 `Component` / `Operator` / `ActionKind` 等均为闭合联合类型，IDE 自动补全 |
| **插件扩展** | 注册自定义 Action、SidePanel、Workflow 渲染器 |

## 现有资源

系统内置 **35+** 个资源配置，覆盖：

- **系统管理**：用户、角色、权限、菜单、字典、系统客户端
- **业务运营**：标注任务、模板管理、分配管理、提交记录
- **标注工作台**：市场、草稿、已提交、奖励记录
- **审核体系**：申诉、验收、抽样
- **资产模块**：文件素材、导出任务

## 快速开始

```bash
# 看看已有资源
ls frontend/src/low-code-resources/

# 编写新的资源配置
# 1. 在 frontend/src/low-code-resources/ 下新建 xxx.ts
# 2. 在 register.ts 的 ALL_RESOURCES 中注册
# 3. 菜单配置 resourceKey 指向该资源
```
