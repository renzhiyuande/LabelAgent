# AI Coding Record

这页面向评委展示 LabelHub 从 0 到 1 的 AI Coding 全过程。内容已经按阶段、模块、时间、业务线和模型记录整理成可直接阅读的过程展陈，不展示内部清洗细节。

## 页面目标

这份 AI Coding Record 主要回答四个问题：

1. 如何证明这是一个真实发生过的 AI Coding 过程，而不是事后编造。
2. 平台是如何从架构设计、系统基建逐步推进到业务开发和后续维护的。
3. 哪些模块是核心建设重点，分别对应了哪些 AI 协作记录。
4. 高质量提示词是如何帮助 AI 在设计、实现、审查和纠偏中持续收敛的。

## 为什么这样设计

这样做有三个直接好处：

1. 叙事清晰。
   先总览，再按阶段、模块和时间展开，评委可以快速建立整体认知。
2. 过程完整。
   页面保留了完整的指导型 prompt 记录，而不是只给摘要或截图。
3. 便于答辩。
   可以按 `阶段卡片 -> 模块分类 -> 时间推进 -> 指导型 Prompt` 的顺序完整讲述平台建设过程。

## 交付方式

下面这块 IDE 式过程浏览器读取的是整理后的 narrative session 与对话 turn。建议按这个顺序使用：

1. 左侧 Sessions 树选择项目 / 日期 / Session
2. 中间查看 user / assistant 自然对话流
3. 右侧查看阶段、模块、工具与模型元数据
4. 需要总览时切到 Stats，或按模块 / 阶段视图筛选
