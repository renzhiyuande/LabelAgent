# LabelHub 数据标注平台

LabelHub 是一个可扩展的 **数据标注与 AI 辅助审核平台**，提供从标注模板设计、任务分配、标注执行、AI 辅助到多级审核的全链路能力。

## 模块概览

| 模块 | 技术栈 | 说明 |
|------|--------|------|
| **低代码引擎** | React + Refine | Schema 驱动 CRUD 后台页面，35+ 资源配置 |
| **工作台框架** | React + DnD Kit | Widget 化布局引擎，v1 三面板 / v2 Tab+Region |
| **模板设计器** | React + Zustand | 可视化标注模板 Schema 编辑器，18 种组件 |
| **标注工作台** | Workbench v2 | 标注员核心操作界面，AI 辅助 |
| **审核工作台** | Workbench v2 | AI 预审 + 人工审核池 |
| **后端服务** | Java 21 + Spring Boot | 分层多模块架构，状态机 + outbox + 预留扩展缝 |
| **Python Agent** | FastAPI + Pydantic | LLM 统一接入网关，provider 抽象 |
