# 01 — 标注市场

> **所属角色**：标注员（Labeler）  
> **入口路由**：`/labeler/market`  
> **关联操作**：[02 — 我的任务与认领](./claim)、[03 — 标注工作台](./annotation)

---

## 1. 场景概述

标注市场是标注员浏览和选择待认领任务的入口。Owner 发布且开放的标注任务在此集中展示，标注员可查看任务详情后认领题目。

---

## 2. 操作步骤

### 步骤 1：进入标注市场

**操作路径**：侧边栏 → 「标注任务」→「标注市场」

![标注市场](/img/demo/screenshots/Labeler_任务广场.png)

页面以列表形式展示可认领任务，包含任务名称、类型、总量、剩余量、截止时间与酬劳等信息。

### 步骤 2：筛选任务

| 筛选条件 | 说明 |
|----------|------|
| 任务类型 | 按标注类型筛选 |
| 任务状态 | 进行中 / 已截止 / 已满额 |
| 酬劳范围 | 按每题酬劳区间筛选 |
| 发布时间 | 按创建时间排序 |

**操作：**
1. 设置筛选条件
2. 点击「查询」执行筛选
3. 点击「重置」清除条件

### 步骤 3：查看任务详情

点击任务行查看完整信息：

- **任务描述**：背景说明与标注要求
- **标注指南**：规范文档链接
- **任务统计**：总题数、已认领、完成进度
- **参与标注员**：当前参与者列表

### 步骤 4：认领任务

在任务详情页点击 **「认领任务」**，确认题量后系统分配题目，成功后跳转至「我的任务」。

> **注意**：同一任务可多次认领，每次分配一批新题目（受单次上限与剩余量限制）。

---

## 4. 关键规则与约束

| 规则 | 说明 |
|------|------|
| **认领上限** | 单次认领数量由 Owner 在创建任务时设定 |
| **重复认领** | 已认领题目不会重复分配 |
| **截止机制** | 超过截止时间的任务不可认领 |
| **满额机制** | 剩余量为 0 时标记「已满额」 |

---

## 5. 常见问题

### Q1: 为什么有些任务无法认领？

可能原因：任务已截止、剩余量为 0、或当前账号无 Labeler 角色权限。

### Q2: 认领后如何开始标注？

在「我的任务」页面点击任务行，进入 [标注工作台](./annotation) 逐题作答。

### Q3: 一个任务可以分多次认领吗？

可以。只要还有剩余量且未截止，可多次认领。
