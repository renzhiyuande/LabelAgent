# 02 — 我的任务与认领

> **所属角色**：标注员（Labeler）  
> **入口路由**：`/labeler/tasks`  
> **关联操作**：[01 — 标注市场](./market)、[03 — 标注工作台](./annotation)

---

## 1. 场景概述

「我的任务」是标注员管理已认领任务的核心页面。在此查看各任务的标注进度、截止时间与状态，并进入工作台作答。

---

## 2. 操作步骤

### 步骤 1：在标注市场认领

**前置操作**：在 [标注市场](./market) 选择任务并点击「认领任务」。

认领流程：

```
查看任务详情
     │
     ├── 无权限 / 已截止 / 已满额 ──→ 提示不可认领
     │
     └── 可认领 ──→ 确认题量 ──→ 系统分配 ──→ 跳转我的任务
```

### 步骤 2：查看我的任务列表

**操作路径**：侧边栏 → 「标注任务」→「我的任务」

![我的任务](/img/demo/screenshots/Labeler_我的任务.png)

| 字段 | 说明 |
|------|------|
| 任务名称 | 标注任务标题 |
| 已标注/总量 | 如 15/20（已完成 / 总题数） |
| 状态 | 进行中 / 已完成 |
| 截止时间 | 任务关闭时间 |
| 操作 | 进入工作台 |

### 步骤 3：进入工作台

点击任务行进入 [标注工作台](./annotation)，开始逐题作答。

### 步骤 4：查看草稿与已提交

| 页面 | 路由 | 说明 | 截图 |
|------|------|------|------|
| 我的草稿 | `/labeler/drafts` | 已保存但未正式提交 | ![我的草稿](/img/demo/screenshots/Labeler_我的草稿.png) |
| 已提交 | `/labeler/submitted` | 已提交待审核或已通过 | ![已提交](/img/demo/screenshots/Labeler_已提交.png) |

## 4. 关键规则与约束

| 规则 | 说明 |
|------|------|
| **角色权限** | 必须拥有 Labeler 角色 |
| **任务状态** | 任务须处于「进行中」 |
| **剩余量 > 0** | 任务还有可分配题目 |
| **未超截止时间** | 当前时间在截止之前 |
| **认领数量** | 可在单次上限内调整本次认领题量 |

---

## 5. 常见问题

### Q1: 认领后想放弃怎么办？

已认领但未开始的题目可联系管理员释放；已开始标注的题目需继续完成或联系 Owner 处理。

### Q2: 认领后任务突然消失了？

可能原因：任务被 Owner 关闭、账号权限变更。刷新页面确认，持续异常请联系管理员。

### Q3: 认领会扣减酬劳吗？

认领时不扣减。酬劳在标注提交且审核通过后结算。
