# 03 — 标注工作台

> **所属角色**：标注员（Labeler）  
> **入口路由**：`/labeler/work/:assignmentId`  
> **关联操作**：[02 — 我的任务与认领](./claim)、[01 — 标注市场](./market)

---

## 1. 场景概述

标注工作台是标注员执行标注任务的核心界面，采用 **四区域 Tab 布局**（Top / Left / Center / Right），支持逐题作答、草稿保存、正式提交与 AI 辅助。

![标注工作台演示](/img/demo/screenshots/05-labeler-workbench.png)

![标注工作台全页](/img/labeler-workbench-fullpage.png)

### 1.1 布局分区

| 区域 | 宽度 | 内容 | 可折叠 |
|------|------|------|--------|
| **Top（顶部工具栏）** | 104px | 工具菜单、进度、题号切换、禅模式 | 否 |
| **Left（左侧队列）** | 296px | 题目列表、状态筛选 | 是 |
| **Center（中间题面）** | fill | 任务上下文、模型回答对比 | 否 |
| **Right（右侧作答）** | 420px | 标注表单、AI 辅助、提交操作 | 是 |

## 2. 操作步骤

### 步骤 1：进入工作台

**操作路径**：「我的任务」→ 点击任务行

或直接访问 `/labeler/work/:assignmentId`

### 步骤 2：查看题面

中间栏（Center）展示题目信息：

| 信息项 | 说明 |
|--------|------|
| 任务名称 / 题号 | 当前题目上下文 |
| 任务类型 | 如 PREFERENCE_COMPARE |
| 样本 ID | 数据样本唯一标识 |
| 用户输入 | 标注问题/指令 |
| 回答 A / 回答 B | 两个模型的输出对比 |
| 打回意见 | 若曾被审核打回，顶部展示上一轮意见 |

### 步骤 3：填写标注表单

右侧栏（Right）主要字段（带 `*` 为必填）：

| 字段 | 类型 | 必填 | 说明 |
|------|------|:----:|------|
| **偏好结论** | 单选 | ✅ | A 更优 / B 更优 / 平局 |
| **优势程度** | 单选 | ✅ | 明显优于 / 略优于 / 相当 |
| **判断依据维度** | 多选 | ✅ | 从 14 个维度中选择 |
| **安全风险** | 单选 | ✅ | 是 / 否 |
| **一句话结论** | 短文本 | ✅ | 简洁偏好总结 |
| **判断理由** | 多行文本 | ✅ | 详细对比分析 |
| **改写/修订建议** | 富文本 | ❌ | 对选中回答的优化建议 |

### 步骤 4：保存或提交

| 操作 | 按钮 | 快捷键 | 行为 |
|------|------|--------|------|
| **保存草稿** | `保存草稿` | `Ctrl + S` | 状态保持「草稿」，仅自己可见 |
| **正式提交** | `正式提交` | `Ctrl + Enter` | 进入审核队列，状态变为「已提交」 |

> **自动保存**：页面 2 秒无操作后自动保存草稿。

### 步骤 5：切换题目

- 左侧栏点击题目
- `←` / `→` 切换上一题/下一题
- 顶部工具栏箭头按钮

### 步骤 6：使用 AI 辅助

1. 右侧「智能辅助」区域点击 **「生成 AI 参考」**
2. 查看 AI 推荐结论与理由
3. 参考后自行填写表单（AI 不参与提交）

## 3. 操作流程图

```
进入工作台
    │
    ├── 查看题面（Center）
    │
    ├── 填写表单（Right）
    │   ├── 保存草稿（Ctrl+S）
    │   └── 正式提交（Ctrl+Enter）
    │
    ├── 切换题目（Left 队列 / ← →）
    │
    └── 全部完成 ──→ 返回我的任务
```

### 3.1 题目状态流转

```
草稿 ──→ 正式提交 ──→ 已提交 ──→ 审核中 ──→ 已通过
  ↑                        │         └──→ 已驳回
  └── 保存草稿 ──────────┘
                            需修改 ←── 审核打回
                              ↓
                        修改后重新提交
```

---

## 4. 关键规则与约束

| 规则 | 说明 |
|------|------|
| **提交后不可改** | 正式提交后须等审核员打回才能修改 |
| **草稿可见性** | 草稿仅标注员本人可见 |
| **AI 辅助** | 运行时生成，不参与提交，标注员对结果负责 |
| **禅模式** | 隐藏侧栏，专注题面与表单 |

### 4.1 队列状态筛选

| 标签 | 说明 |
|------|------|
| 全部 | 所有题目 |
| 待作答 | 尚未开始 |
| 已提交 | 已提交审核中 |
| 需修改 | 被打回待修改 |
| 已通过 | 审核通过 |
| 已驳回 | 审核驳回（最终定论） |

---

## 5. 常见问题

### Q1: 提交后还能修改吗？

提交后进入审核队列，不可直接修改。仅审核员**打回**后可重新作答。

### Q2: 草稿和正式提交有什么区别？

| 维度 | 草稿 | 正式提交 |
|------|------|----------|
| 可见性 | 仅自己 | 审核员可见 |
| 审核流程 | 不进入 | 进入审核队列 |

### Q3: AI 参考可以代替人工标注吗？

不可以。AI 仅作辅助，标注员对结果负责。
