# 角色权限管理

> **适用角色**：系统管理员（Admin）  
> **关联文档**：[系统管理员角色概述](./overview)、[用户管理](./user-management)、[系统配置管理](./system-config)

---

## 1. 功能说明

角色权限管理页面定义系统的角色体系，每个角色关联一组权限点。管理员可创建自定义角色、配置权限树、管理角色与用户的关联关系。

![角色管理](/img/admin-roles.png)

---

## 2. 操作流程

```
进入角色管理 → 查看角色列表
       → 创建角色 / 编辑角色
       → 配置权限树
       → 查看角色下的用户
```

---

## 3. 分步操作

### 步骤 1：进入角色管理

- 登录 LabelHub 管理后台
- 在侧边栏点击 **「系统管理」** → **「角色管理」**
- 或直接访问 `/system/roles`

### 步骤 2：查看角色列表

角色列表展示所有已定义的角色：

| 信息 | 说明 |
|------|------|
| 角色名称 | 角色的显示名称 |
| 角色编码 | 角色的唯一标识符 |
| 角色描述 | 角色的职责说明 |
| 关联用户数 | 该角色下的用户数量 |

### 步骤 3：了解内置角色

| 角色 | 说明 | 典型权限范围 |
|------|------|-------------|
| **Admin** | 系统管理员 | 全部系统管理权限 |
| **Owner** | 任务负责人 | 任务创建、模板搭建、数据管理 |
| **Reviewer** | 审核员 | AI 预审队列、人工审核池、审核结果 |
| **Labeler** | 标注员 | 标注市场、标注作答、我的任务 |

### 步骤 4：创建自定义角色

点击「创建角色」，填写：

| 字段 | 说明 |
|------|------|
| 角色名称 | 自定义角色名称 |
| 角色编码 | 全局唯一的角色编码 |
| 角色描述 | 角色职责说明 |

### 步骤 5：配置权限树

权限结构为树形层级：

```
系统管理
├── 用户管理
│   ├── 查询用户
│   ├── 创建用户
│   ├── 编辑用户
│   └── 删除用户
├── 角色管理
│   ├── 查询角色
│   ├── 创建角色
│   └── 编辑角色
├── 系统配置
│   ├── 字典管理
│   └── 客户端管理
...
```

> **勾选父级节点**自动继承其下所有子权限。

### 步骤 6：查看角色下的用户

点击角色的「查看用户」操作，查看该角色关联的所有用户列表。也可在用户管理中为用户分配角色。

## 4. 权限管理要点

```
权限检查流程：

用户请求接口
     │
     ▼
获取用户的所有角色
     │
     ▼
合并角色的所有权限
     │
     ▼
判断是否包含所需权限
     │
  ┌──┴──┐
  │     │
 有权限  无权限
  │     │
 通过   拒绝（403）
```

- 角色权限修改后对已登录用户**立即生效**（下次请求时重新加载权限）
- 删除角色前需确保该角色下无关联用户

---

## 5. 常见问题

### Q1: 内置角色可以修改吗？

内置角色的名称和描述可修改，但建议保留其原始的权限结构。如需调整权限，建议创建自定义角色。

### Q2: 角色权限修改后何时生效？

角色权限修改后对已登录用户**立即生效**（下次请求时重新加载权限），无需重新登录。

### Q3: 可以限制某个角色的数据可见范围吗？

可以。通过「数据权限」配置（位于系统管理中）可设置角色的数据可见范围，如全部数据、按组织、按用户等。

### Q4: 一个用户可以没有角色吗？

不可以。每个用户至少需要一个角色才能正常访问系统。建议为每个用户分配必要的角色。
