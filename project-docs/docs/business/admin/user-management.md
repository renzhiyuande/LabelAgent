# 用户管理

> **适用角色**：系统管理员（Admin）  
> **关联文档**：[系统管理员角色概述](./overview)、[角色权限管理](./role-permission)、[系统配置管理](./system-config)

---

## 1. 功能说明

用户管理页面管理平台所有用户账号，支持用户创建、编辑、角色分配、状态管理等。

![用户管理](/img/admin-users.png)

---

## 2. 操作流程

```
进入用户管理 → 查看用户列表（支持搜索/筛选）
       → 创建新用户 / 编辑现有用户
       → 分配角色 / 启用禁用 / 重置密码
```

---

## 3. 分步操作

### 步骤 1：进入用户管理

- 登录 LabelHub 管理后台
- 在侧边栏点击 **「系统管理」** → **「用户管理」**
- 或直接访问 `/system/users`

### 步骤 2：查看用户列表

用户列表展示所有平台用户，支持：

| 操作 | 说明 |
|------|------|
| 搜索 | 按用户名、昵称、邮箱搜索 |
| 筛选 | 按角色、状态（启用/禁用）筛选 |
| 排序 | 按创建时间、更新时间排序 |

### 步骤 3：创建用户

点击「创建用户」按钮，填写以下信息：

| 字段 | 必填 | 说明 |
|------|:----:|------|
| 用户名 | ✅ | 登录用户名，全局唯一 |
| 昵称 | ❌ | 显示名称 |
| 邮箱 | ✅ | 用户邮箱，可用于找回密码 |
| 手机号 | ❌ | 用户手机号 |
| 角色 | ✅ | 用户角色（Owner/Labeler/Reviewer 等） |
| 状态 | ✅ | 启用/禁用 |
| 备注 | ❌ | 管理备注 |

### 步骤 4：分配角色

- 在用户详情页点击「分配角色」
- 选择该用户需要拥有的一个或多个角色
- 保存后即时生效

### 步骤 5：管理用户状态

| 操作 | 说明 |
|------|------|
| **启用/禁用** | 控制用户账号的登录权限，禁用后用户无法登录 |
| **重置密码** | 重置用户登录密码，重置后用户下次登录需使用新密码 |
| **删除用户** | 删除用户账号（软删除，可恢复） |

---

## 4. 用户状态流转

```
创建用户（启用）
     │
     ├── 启用状态 ──→ 正常登录使用
     │                    │
     │               ┌────┴────┐
     │               │         │
     │            禁用账号   删除账号
     │               │         │
     │           无法登录   不可恢复
     │               │
     └── 禁用状态 ──→ 启用恢复
```

---

## 5. 常见问题

### Q1: 创建用户后如何通知用户登录？

创建用户后，系统不会自动发送通知。建议手动告知用户其用户名和初始密码，用户首次登录后应修改密码。

### Q2: 用户被禁用后数据会丢失吗？

不会。禁用用户仅限制其登录权限，该用户创建的标注、审核等数据仍然保留。

### Q3: 一个用户可以拥有多个角色吗？

可以。一个用户可以同时拥有 Owner、Labeler、Reviewer 等多个角色，拥有所有角色的权限合集。

### Q4: 删除用户后可以恢复吗？

系统使用软删除机制，可通过数据库恢复。建议使用「禁用」替代删除操作。

### Q5: 密码有什么复杂度要求？

密码需要满足系统配置的复杂度策略，通常要求包含大小写字母、数字和特殊字符，长度不少于 8 位。
