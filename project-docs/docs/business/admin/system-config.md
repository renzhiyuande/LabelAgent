# 系统配置管理

> **适用角色**：系统管理员（Admin）  
> **关联文档**：[系统管理员角色概述](./overview)、[用户管理](./user-management)、[角色权限管理](./role-permission)

---

## 1. 功能说明

系统配置管理涵盖平台运行时所需的各类配置项，包括 LLM 提供商、字典、菜单、维度包、数据权限以及运维管理功能。

---

## 2. LLM 提供商配置

### 2.1 功能说明

配置平台使用的 AI 模型提供商，支持 OpenAI 兼容协议和自定义 Provider。

### 2.2 操作步骤

1. 进入 **「系统管理」** → **「LLM 提供商」**
2. 点击「创建提供商」

| 配置项 | 说明 |
|--------|------|
| 提供商名称 | 如 OpenAI、DeepSeek、通义千问 |
| API 地址 | LLM 服务的 API 端点 |
| API Key | 认证密钥（加密存储） |
| 模型列表 | 可用的模型名称列表 |
| 超时配置 | 请求超时时间 |
| 重试策略 | 失败重试次数 |

3. 保存后即可在审核 Prompt 配置中选择使用

### 2.3 支持的提供商

| 类型 | 说明 | 示例 |
|------|------|------|
| OpenAI 兼容协议 | 通过 base_url + api_key 接入 | DeepSeek、通义千问 |
| 自定义 Provider | 实现特定协议适配 | Anthropic、Gemini |

## 3. 字典配置

### 3.1 功能说明

系统字典用于管理枚举值和下拉选项，如任务类型、审核状态等。

### 3.2 操作步骤

| 操作 | 说明 |
|------|------|
| 创建字典 | 定义字典编码、名称 |
| 添加字典项 | 为字典添加键值对（编码 + 显示值） |
| 排序 | 调整字典项显示顺序 |
| 导入/导出 | 批量导入/导出字典数据 |

> **注意**：字典数据变更后，前端需要**刷新页面**或清除缓存才能看到最新数据。

## 7. 运维管理

### 7.1 审计日志

记录平台所有关键操作，用于安全审计：

| 信息 | 说明 |
|------|------|
| 操作人 | 执行操作的用户 |
| 操作类型 | 登录/创建/修改/删除等 |
| 操作对象 | 操作的目标资源 |
| 操作时间 | 精确到毫秒 |
| IP 地址 | 操作来源 IP |
| 操作详情 | 请求参数与响应摘要 |

### 7.2 异步任务

查看和管理后台异步任务的执行状态：

| 状态 | 说明 |
|------|------|
| PENDING | 等待执行 |
| RUNNING | 正在执行 |
| SUCCESS | 执行成功 |
| FAILED | 执行失败 |
| RETRYING | 重试中 |

### 7.3 定时任务

管理平台的定时任务调度：

| 操作 | 说明 |
|------|------|
| 查看任务 | 查看所有定时任务及其调度状态 |
| 执行日志 | 查看每次执行的日志 |
| 手动触发 | 手动触发一次任务执行 |
| 暂停/恢复 | 控制任务调度 |

## 8. 常见问题

### Q1: 如何配置 LLM 提供商？

进入「系统管理」→「LLM 提供商」，填写 API 地址和 Key。支持 OpenAI 兼容协议的所有服务商可直接使用，其他协议需配置对应 Provider。

### Q2: 字典数据变更后前端何时更新？

字典数据由前端缓存，修改后需要**刷新页面**或清除缓存才能看到最新数据。

### Q3: 如何定位系统异常？

优先查看「审计日志」确认操作记录，然后查看「异步任务」确认后台任务状态，必要时查看后端应用日志。

### Q4: 数据权限和角色权限有什么区别？

- **角色权限**：控制用户能否访问某个功能（如能否看到用户管理页面）
- **数据权限**：控制用户能访问哪些数据（如只能看到自己创建的任务，还是能看到所有任务）
