# 系统管理员（Admin）操作指南

> **适用角色**：系统管理员（Admin）  
> **工作流程**：用户管理 → 角色权限 → 系统配置  
> **关联文档**：[整体架构](../../architecture)、[开发指南](../../development/conventions)

---

## 1. 角色概览

系统管理员负责 LabelHub 平台的系统级配置与运维管理，包括用户管理、角色权限、系统配置、字典管理等。

### 1.1 功能入口

管理员的工作台位于侧边栏 **「系统管理」** 分组下，包含以下主要功能页面：

| 菜单 | 路由 | 说明 |
|------|------|------|
| **用户管理** | `/system/users` | 平台用户账号管理 |
| **角色管理** | `/system/roles` | 角色定义与权限分配 |
| **权限管理** | `/system/permissions` | 系统权限点管理 |
| **菜单管理** | `/system/menus` | 侧边栏菜单配置 |
| **字典配置** | `/system/dicts` | 系统字典与枚举管理 |
| **LLM 提供商** | `/system/llm-providers` | LLM 模型提供商配置 |
| **审计日志** | `/system/audit` | 操作审计日志查询 |
| **异步任务** | `/system/async` | 异步任务管理与监控 |

## 3. 常见问题

### Q1: 创建用户后如何通知用户登录？

创建用户后，系统不会自动发送通知。建议手动告知用户其用户名和初始密码，用户首次登录后应修改密码。

### Q2: 角色权限修改后何时生效？

角色权限修改后对已登录用户**立即生效**（下次请求时重新加载权限），无需重新登录。

### Q3: 如何配置 LLM 提供商？

进入「系统管理」→「LLM 提供商」，填写 API 地址和 Key。支持 OpenAI 兼容协议的所有服务商可直接使用，其他协议需配置对应 Provider。

### Q4: 字典数据变更后前端何时更新？

字典数据由前端缓存，修改后需要**刷新页面**或清除缓存才能看到最新数据。

### Q5: 如何定位系统异常？

优先查看「审计日志」确认操作记录，然后查看「异步任务」确认后台任务状态，必要时查看后端应用日志。
