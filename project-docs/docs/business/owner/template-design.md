# 02 — 模板搭建

> **所属角色**：任务负责人（Owner）  
> **入口路由**：`/system/template-designer`（模板搭建器）  
> **关联操作**：[01-任务管理](./task-management)、[03-创建任务](./task-create)

---

## 1. 场景概述

模板搭建器是 LabelHub 的**可视化标注表单编辑器**。Owner 通过**拖拽组件**到画布，构建标注表单 Schema，无需编写代码。生成的表单将用于标注员执行标注任务时填写。

---

## 2. 页面布局

![模板设计器演示](/img/demo/screenshots/03-template-designer.png)

![模板搭建器标注](/img/owner/designer-annotated.png)

模板搭建器采用**三面板布局**：

| 标注 | 区域 | 说明 |
|:----:|------|------|
| **①** | **顶部工具栏** | 模板名称、版本、操作按钮（预览/审核配置/保存/发布/版本历史） |
| **②** | **组件库（左侧）** | 可拖拽的组件面板，按分类组织 |
| **③** | **画布（中间）** | 表单设计区域，拖入组件进行编辑 |
| **④** | **属性面板（右侧）** | 选中组件后的属性编辑区 |
| **⑤** | **组件分类** | 基础/高级/展示/智能辅助四类 |

## 3. 操作步骤

### 步骤 1：创建/打开模板

**入口：** 侧边栏「数据生产中心」→「模板搭建」或仪表盘「打开模板搭建器」

**操作：**
1. 点击「新建模板」开始创建新模板
2. 双击顶部标题区域（显示「新建模板」）重命名
3. 系统自动创建初始版本（v1.0.0）

**或从模板市场选用：**
1. 在模板市场浏览已发布模板
2. 点击「选用」创建基于该模板的副本

### 步骤 2：拖拽组件构建表单

![模板搭建器全页](/img/owner/designer-full.png)

**从组件库拖拽组件到画布：**

| 组件分类 | 包含组件 | 数量 | 用途 |
|----------|----------|:----:|------|
| **基础组件** | 单行输入、多行文本、富文本、单选下拉、多选下拉、标签选择、单选组、多选组、开关 | 9 | 基础表单字段 |
| **高级组件** | 远程选择、JSON 编辑、文件上传、图片上传、数组/子表单 | 5 | 复杂场景 |
| **展示组件** | 展示项、展示图片、展示文件、展示视频 | 4 | 只读展示 |
| **智能辅助** | LLM 推荐 | 1 | AI 辅助填写 |

**拖拽操作：**
1. 鼠标长按左侧组件
2. 拖拽到画布的目标位置（蓝色指示线标识放置位置）
3. 松开鼠标完成放置

### 步骤 3：配置字段属性

在画布中**点击选中**组件后，右侧属性面板展示以下 Tab：

**Tab 1：基础（Basic）**

| 配置项 | 说明 |
|--------|------|
| 标题 | 字段显示名称 |
| 字段 Key | 字段唯一标识（数据字段名） |
| 路径 | 字段在数据结构中的路径 |
| 导入角色 | 数据导入时的角色映射 |
| 组件类型 | 当前使用的组件类型（可切换） |
| Placeholder | 输入占位提示文字 |
| 描述 | 字段帮助说明 |
| Span | 字段宽度占比 |
| 必填 | 是否为必填字段 |
| 只读 | 是否只读 |
| 隐藏 | 是否在表单中隐藏 |

**Tab 2：组件（Component）**

根据所选组件类型展示不同的配置项：
- **单选下拉**：选项列表（key-value）
- **远程选择**：远程数据源 URL、依赖字段
- **文件上传**：存储桶、文件类型限制
- **JSON 编辑**：JSON Schema 定义
- **LLM 推荐**：AI 提示词配置

**Tab 3：校验（Validation）**

| 配置项 | 说明 |
|--------|------|
| 正则表达式 | 输入格式校验规则 |
| 最小/最大值 | 数值范围校验 |
| 最小/最大长度 | 文本长度校验 |
| 自定义校验 | 自定义校验函数 |

**Tab 4：联动（Linkage）**

| 配置项 | 说明 |
|--------|------|
| visibleWhen | 字段显隐条件（如：当 `字段A = 值X` 时显示） |
| disabledWhen | 字段禁用条件 |

### 步骤 4：管理区块（Section）

画布顶部 Tab 栏管理表单的分区：

| 操作 | 说明 |
|------|------|
| **新增区块** | 点击 Tab 栏右侧的「+」按钮 |
| **重命名** | 双击区块 Tab 名称 |
| **删除** | 悬停 Tab 后点击删除图标（至少保留 1 个） |
| **切换编辑** | 点击 Tab 切换当前编辑的区块 |

### 步骤 5：预览表单

点击顶部工具栏「预览」按钮，切换到**标注员视角**查看表单效果。

预览模式下：
- 使用样本数据渲染
- 可测试校验规则
- 可测试联动条件
- 点击「退出预览」返回编辑模式

### 步骤 6：配置审核流程

点击「审核配置」打开审核配置抽屉：

![审核配置](/img/owner/designer-review-config.png)

| 配置项 | 说明 |
|--------|------|
| **审核级别** | 单级 / 二级 / 三级审核 |
| **各级名称** | 自定义各审核阶段的显示名称 |
| **可用操作** | 各级审核员可执行的操作（通过/驳回/退回修改） |
| **LLM 审核 Prompt** | AI 预审使用的 Prompt 模板 |
| **审核维度** | AI 预审评估维度配置 |

### 步骤 7：版本管理

点击「版本历史」查看和管理模板版本：

![版本历史](/img/owner/designer-version-history.png)

| 操作 | 说明 |
|------|------|
| **查看版本列表** | 展示所有历史版本及状态 |
| **创建快照** | 基于当前版本创建新草稿 |
| **回滚** | 回滚到指定已发布版本 |
| **切换草稿** | 在同模板的多个草稿间切换 |

### 步骤 8：保存与发布

| 操作 | 按钮 | 说明 |
|------|------|------|
| **保存草稿** | 「保存草稿」 | 保存当前编辑进度 |
| **发布** | 「发布」 | 发布为正式可用版本 |
| **导出 Schema** | 「导出 FormSchema」 | 导出模板 Schema JSON |

## 5. 关键规则

| 规则 | 说明 |
|------|------|
| **发布后不可修改** | 已发布版本为只读，修改需创建新草稿 |
| **模板与任务绑定** | 任务发布后关联的模板版本不可更换 |
| **导入契约锁定** | 通过数据导入创建的模板，字段 path 被锁定 |
| **校验与联动** | 支持正则校验和条件显隐/禁用联动 |
| **最少一个区块** | 画布至少保留一个 Section |

## 6. 最佳实践

### 通用标注表单

```
Section 1：基本信息
  展示项：样本 ID（只读）
  展示图片：输入图片（只读）
  单行输入：用户输入

Section 2：标注内容
  单选组：偏好结论（A 更优 / B 更优 / 平局）
  单选组：优势程度（明显优于 / 略优于 / 相当）
  多选组：判断依据维度
  多行文本：判断理由
```

### 命名规范

- 字段 Key 统一使用 `snake_case`：`preference_conclusion`
- Section 名称清晰表达用途：`基本信息`、`标注内容`

## 7. 常见问题

### Q1: 发布后如何修改模板？

通过「版本历史」→「创建快照」生成新草稿 → 编辑 → 重新发布。已有任务仍使用旧版本，新任务可选择新版本。

### Q2: 拖拽组件到画布后没有显示？

检查左侧组件分类是否已展开（点击分类名展开/折叠）。如果组件已存在但不可见，检查画布是否滚动到其他 Section。

### Q3: 如何配置多级审核？

在「审核配置」中设置审核级别为二级或三级，为每级配置审核人角色和可用操作。

### Q4: 如何测试联动条件？

点击「预览」模式，使用样本数据测试字段的显隐和禁用条件是否按预期工作。
