# 01 — 任务管理

> **所属角色**：任务负责人（Owner）  
> **入口路由**：`/owner/tasks`  
> **关联操作**：[模板搭建](./template-design)、[创建任务](./task-create)

---

## 1. 场景概述

任务管理是 Owner 的**核心工作台首页**，用于查看所有标注任务的状态、配置和进度，并对任务进行新建、编辑、发布、暂停、归档等全生命周期管理。

---

## 2. 操作步骤

### 步骤 1：进入任务管理

**操作路径**：侧边栏 → 「数据生产中心」→「任务管理」

![任务管理演示](/img/demo/screenshots/Owner_任务管理.png)

![任务管理页面标注](/img/owner/owner-tasks-annotated.png)

页面分为以下功能区：

| 标注 | 区域 | 用途 |
|:----:|------|------|
| **①** | **新建标注任务** | 点击跳转创建任务流程 |
| **②** | **查询筛选区** | 按关键词、状态、场景筛选任务列表 |
| **③** | **任务数据表格** | 展示全部任务的概要信息 |
| **④** | **状态标签** | 彩色标签标识任务当前生命周期状态 |
| **⑤** | **行操作按钮** | 详情 / 编辑 / 更多菜单（⋮） |
| **⑥** | **分页导航** | 翻页、跳转到指定页码 |

### 步骤 2：筛选任务

**筛选条件说明：**

| 条件 | 控件类型 | 说明 |
|------|----------|------|
| **关键词** | 文本框 | 按任务名称或描述模糊搜索 |
| **任务状态** | 下拉选择 | 全部 / 草稿 / 已发布 / 已暂停 / 已完成 / 已归档 |
| **标注场景** | 文本框 | 按标注场景类型筛选 |

**操作：**
1. 在「任务名称 / 描述」输入框中输入关键词
2. 在「任务状态」下拉框中选择目标状态
3. 点击「查询」按钮执行筛选
4. 点击「重置」清除所有筛选条件

### 步骤 3：查看任务列表

表格包含以下字段：

| 列 | 排序 | 说明 |
|:--:|:----:|------|
| 编码 | ✅ | 任务唯一编码（如 `TASK_PREF_COMPARE_DEMO`） |
| 任务名称 | ✅ | 任务的显示名称 |
| 状态 | ✅ | 见下方「状态说明」 |
| 数据量 | ✅ | 标注题目总数 |
| 发布就绪 | ❌ | 模板与数据是否就绪（可发布 / 不可发布 / 阻塞原因） |
| 截止时间 | ✅ | 标注提交截止日期 |
| 更新时间 | ✅ | 最近一次修改时间（默认降序） |
| 操作 | — | 详情、编辑、更多操作 |

> **技巧**：点击列头的 ↕ 图标可按该列排序（升序/降序切换）。

### 步骤 4：状态识别

**任务状态标签颜色说明：**

| 状态 | 标签颜色 | 含义 | 可执行操作 |
|:----:|:--------:|------|-----------|
| **草稿** | 🟡 灰色 | 创建中，尚未发布 | 编辑、删除 |
| **已发布** | 🟢 绿色 | 已发布到市场，标注员可领取 | 暂停、编辑 |
| **已暂停** | 🟠 橙色 | 标注暂停中，标注员不可继续 | 恢复、归档 |
| **已完成** | 🔵 蓝色 | 所有标注题目已全部提交 | 归档、验收 |
| **已归档** | ⚪ 浅灰 | 任务已关闭归档 | 查看、导出数据 |

### 步骤 5：查看任务详情

**操作：** 点击目标行的「详情」按钮

![任务详情抽屉](/img/owner/owner-task-detail.png)

详情以 **抽屉面板** 形式展示，包含两个 Tab：

#### Tab 1：基础信息

| 信息组 | 包含字段 |
|--------|----------|
| **基本属性** | 任务编码、任务名称、任务描述、标注场景、任务状态 |
| **发布状态** | 发布就绪摘要、模板就绪、可发布、发布阻塞原因 |
| **模板信息** | 当前模板版本 ID |
| **分发策略** | 分发策略类型（如：先到先得） |
| **数据配置** | 数据总量、单人最大领取数量 |
| **奖励规则** | 规则类型、币种、结算单位、单条奖励金额 |
| **审核流程** | 审核级别及各级的展示名称、可用操作 |
| **任务设置** | 允许撤回/申诉及其次数、时效、是否允许平局、展示模型名称 |
| **时间信息** | 截止时间、发布时间、创建时间、更新时间 |

#### Tab 2：任务生命周期

展示任务从创建到归档的完整状态流转时间线。

#### 详情底部操作按钮

| 按钮 | 用途 |
|------|------|
| 导入标注数据 | 跳转到数据导入页面 |
| 模板管理 | 查看关联模板 |
| 编辑模板 | 跳转到模板搭建器编辑模板 |
| 任务分配管理 | 跳转到分配管理页面 |
| 审核员管理 | 配置任务审核员 |
| 提交记录管理 | 查看标注提交记录 |
| 申诉记录 | 查看标注员申诉 |
| 关闭面板 | 关闭详情抽屉 |

### 步骤 6：编辑任务

**操作：** 点击目标行的「编辑」按钮

**可编辑字段：**
- 任务名称、任务描述
- 截止时间
- 任务设置（撤回/申诉开关、次数、时效等）

> **注意**：任务发布后**不可变更模板和数据**——如需更换模板，需创建新任务。

### 步骤 7：发布 / 暂停 / 归档任务

通过行末的「更多」菜单（⋮ 图标）执行状态变更：

| 操作 | 适用状态 | 效果 |
|------|----------|------|
| **发布** | 草稿 | 任务进入市场，标注员可见可领取 |
| **暂停** | 已发布 | 任务暂停，标注员不可继续操作 |
| **恢复** | 已暂停 | 任务恢复至已发布状态 |
| **归档** | 已完成 / 已暂停 | 任务关闭归档，不可再变更 |
| **删除** | 草稿 | 彻底删除草稿任务 |

```
┌────────────────┐
│  任务管理首页    │
```

## 4. 关键规则与约束

| 规则 | 说明 |
|------|------|
| **模板不可变** | 任务发布后，关联的模板版本不可更改 |
| **数据不可变** | 任务发布后，已导入的标注数据不可增删（可补充导入） |
| **状态单向流转** | 草稿 → 已发布 → 已暂停 → 已归档，不可逆向 |
| **删除限制** | 只有「草稿」状态的任务可删除 |
| **发布前置条件** | 必须在选定模板且数据已导入的情况下才能发布 |

## 5. 常见问题

### Q1: 为什么我的任务无法发布？

检查以下前置条件：
- 是否已选择模板且模板状态为「已发布」
- 是否已导入标注数据
- 「发布就绪」列是否显示「可发布」
- 如果显示阻塞原因，根据提示修复

### Q2: 已发布的任务如何紧急暂停？

在任务列表中找到该任务 → 点击「更多」菜单（⋮）→ 选择「暂停」。暂停后标注员无法继续标注，已提交的标注不受影响。

### Q3: 如何知道任务完成进度？

在详情抽屉的「基础信息」Tab 中查看数据总量，或在「任务分配管理」中查看每个标注员的完成情况。

### Q4: 如何删除一个错误创建的草稿任务？

在任务列表中找到该草稿任务 → 点击「更多」菜单（⋮）→ 选择「删除」。
