# 06 — 数据验收

> **所属角色**：任务负责人（Owner）  
> **入口路由**：`/owner/acceptances`  
> **关联操作**：[01-任务管理](./task-management)、[07-数据导出](./data-export)

---

## 1. 场景概述

数据验收是标注质量控制的最后关口。Owner 在此验收已通过审核的标注数据，确认数据质量满足要求后，进入结算和导出流程。

## 3. 验收流程

```
标注 → AI预审 → 人工审核 → Owner验收 → 结算/导出
                              ├── 通过 → 标记验收
                              └── 驳回 → 退回修改
```

### 验收标准

| 维度 | 说明 |
|------|------|
| 完整性 | 标注字段是否填写完整 |
| 准确性 | 标注内容是否符合要求 |
| 一致性 | 同任务中的标注标准是否一致 |

---

## 4. 常见问题

### Q1: 验收和审核有什么区别？

审核（Reviewer）是对标注质量的评估，验收（Owner）是对已通过审核的数据做最终确认。审核通过的数据不一定自动验收通过。

### Q2: 验收驳回后标注员怎么办？

驳回的数据会标记为「需修改」，标注员修改后可重新提交审核。
