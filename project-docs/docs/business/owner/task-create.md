# 03 — 创建任务

> **所属角色**：任务负责人（Owner）  
> **入口**：任务管理页 → 点击「新建标注任务」  
> **关联操作**：[01-任务管理](./task-management)、[02-模板搭建](./template-design)、[04-任务分配](./task-assignment)

---

## 1. 场景概述

创建标注任务是将模板、数据、奖励规则、审核流程等配置组装为可执行标注作业的核心流程。操作在**右侧抽屉面板**中完成。

---

## 2. 操作入口

**路径：** 侧边栏「数据生产中心」→「任务管理」→ 点击右上角「新建标注任务」

![新建任务抽屉](/img/owner/owner-task-create-drawer.png)

新建任务表单分为 **3 大配置区**，从上到下依次填写。

---

## 3. 配置基础信息

### 3.1 任务基本属性

| 字段 | 必填 | 说明 |
|------|:----:|------|
| **任务编码** | ✅ | 任务唯一标识（如 `TASK_MY_FIRST`） |
| **任务名称** | ✅ | 标注员可见的任务名称 |
| **任务描述** | ❌ | 标注任务说明（标注员可见） |
| **标注场景** | ✅ | 标注场景类型（如 `PREFERENCE_COMPARE`） |

### 3.2 分发策略

| 配置项 | 说明 |
|--------|------|
| **分发策略** | 当前仅支持「先到先得」，标注员自行领取 |
| **单人最大领取数量** | 每个标注员最多可领取的题目数 |

### 3.3 奖励规则

| 配置项 | 说明 |
|--------|------|
| **奖励规则** | 选择计奖方式（如「按通过条数计奖」） |
| **币种** | 人民币 CNY |
| **结算单位** | 按提交计奖（由规则自动确定） |
| **单条奖励金额** | 每条通过的标注发放的金额 |

### 3.4 截止时间

| 配置项 | 说明 |
|--------|------|
| **日期** | 选择截止日期 |
| **时间** | 选择截止具体时间 |

---

## 4. 配置任务设置

### 4.1 提交与申诉

| 配置项 | 默认值 | 说明 |
|--------|:------:|------|
| **允许标注员撤回提交** | ✅ 启用 | 标注员可在审核前撤回提交 |
| **单条最大撤回次数** | 1 | 每条标注最多可撤回次数 |
| **允许标注员申诉** | ❌ 禁用 | 标注员可对审核结果提出申诉 |
| **单条最大申诉次数** | 1 | — |
| **申诉时效（小时）** | 72 | 审核后多少小时内可申诉 |

### 4.2 标注展示

| 配置项 | 默认值 | 说明 |
|--------|:------:|------|
| **允许平局** | ❌ 禁用 | 标注时是否允许选择「平局」结论 |
| **展示模型名称** | ✅ 启用 | 标注员是否可见模型名称 |

---

## 5. 配置审核流程

### 5.1 审核级别

审核流程按顺序配置各级审核：

**默认配置（初审）：**
- 展示名称：初审
- 可用操作：通过 / 驳回 / 退回修改（全部启用）

**可操作：**
- 点击「新增一项」添加复审、终审等
- 最多支持 5 级审核
- 每级至少选择一个可用操作

### 5.2 审核级别说明

| 级别 | 典型名称 | 用途 |
|:----:|----------|------|
| 第 1 级 | 初审 | AI 预审 + 人工快速审核 |
| 第 2 级 | 复审 | 质量抽检、疑难审核 |
| 第 3 级 | 终审 | 最终质量把关 |

---

## 6. 保存任务

底部操作按钮：

| 按钮 | 说明 |
|------|------|
| **取消** | 关闭抽屉，不保存 |
| **保存** | 保存任务为「草稿」状态，可在任务列表中继续编辑 |

> 保存后任务状态为「草稿」，需在任务管理页面手动「发布」才会进入标注市场。

---

## 7. 任务生命周期

```
草稿 ──→ 发布 ──→ 标注中 ──→ 暂停/完成 ──→ 归档
  │          │          │
  │   标注员可领取  标注暂停   数据导出
  │          │          │
  └── 编辑    └── 暂停   └── 恢复
```

---

## 8. 常见问题

### Q1: 保存后还能修改哪些内容？

保存为草稿后可修改全部字段。发布后只能修改名称、描述、截止时间等基本信息，**不可变更模板和已导入数据**。

### Q2: 为什么「新建标注任务」按钮打开的是抽屉不是页面？

创建任务采用**抽屉面板**（Drawer）设计，在当前任务管理页面上方弹出，不影响已有页签。

### Q3: 如何导入标注数据？

创建任务时只配置基本信息。数据导入可通过任务详情抽屉中的「导入标注数据」按钮进入专门的数据导入页面。

### Q4: 奖励规则可以后续修改吗？

任务发布后奖励规则**不可修改**。如需调整，请创建新任务并配置新规则。
