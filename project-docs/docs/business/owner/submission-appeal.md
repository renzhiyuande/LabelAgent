# 05 — 提交与申诉

> **所属角色**：任务负责人（Owner）  
> **入口路由**：`/owner/submissions`（提交记录）、`/owner/appeals`（申诉记录）

---

## 1. 提交记录

![提交记录演示](/img/demo/screenshots/Owner_提交记录.png)

![提交记录](/img/owner/owner-submissions-clean.png)

查看所有标注员提交的标注结果：

| 字段 | 说明 |
|------|------|
| 提交编号 | 提交记录唯一标识 |
| 标注员 | 提交者 |
| 题目 | 提交的题目 |
| 提交时间 | 提交时间 |
| 状态 | 已提交/审核中/已通过/需修改/已驳回 |
| 审核人 | 审核该提交的 Reviewer |
| 操作 | 查看提交详情 |

---

## 2. 申诉记录

![申诉记录](/img/owner/owner-appeals-clean.png)

标注员对审核结果有异议时可申诉：

| 操作 | 说明 |
|------|------|
| 通过申诉 | 同意标注员诉求，修改审核结果 |
| 驳回申诉 | 维持原审核结果 |
| 查看详情 | 查看标注内容与审核意见 |
