# 04 — 任务分配

> **所属角色**：任务负责人（Owner）  
> **入口路由**：`/owner/assignments`  
> **关联操作**：[01-任务管理](./task-management)、[03-创建任务](./task-create)

---

## 1. 场景概述

任务分配管理将标注任务分配给标注员。支持**市场认领**（先到先得）和**指定分配**两种方式，并实时跟踪每个标注员的进度。

---

## 2. 页面布局

![任务分配页面](/img/owner/owner-assignments-clean.png)

| 区域 | 说明 |
|------|------|
| **查询筛选** | 按任务、标注员、状态筛选 |
| **分配列表** | 展示标注员分配记录及进度 |
| **分配操作** | 分配标注员、调整分配量、回收分配 |

---

## 3. 操作步骤

### 步骤 1：筛选查看分配

**筛选条件：**
- 任务名称/编码
- 标注员姓名
- 分配状态（待领取/进行中/已完成/已过期/已取消）

### 步骤 2：分配标注员

**市场认领模式：**
- 任务发布后自动进入标注市场
- 标注员自行领取（受「单人最大领取数量」限制）
- Owner 无需额外操作

**指定分配模式：**
1. 点击「分配标注员」
2. 在弹窗中选择标注员
3. 设置每人分配的题目数量
4. 确认分配

### 步骤 3：跟踪进度

分配列表展示每个标注员的状态：

| 状态 | 说明 | 可操作 |
|------|------|--------|
| **待领取** | 标注员尚未领取 | 可取消分配 |
| **进行中** | 标注员正在标注 | 可调整数量 |
| **已完成** | 全部完成 | 通过验收 |
| **已过期** | 超时未完成 | 回收重新分配 |
| **已取消** | Owner 取消分配 | — |

### 步骤 4：调整分配

| 操作 | 说明 |
|------|------|
| **增加分配** | 增加标注员的题目数量 |
| **减少分配** | 减少标注员的题目数量（不影响已完成的） |
| **回收分配** | 将未完成的题目回收，重新进入分配池 |
| **取消分配** | 完全取消该标注员的分配 |

---

## 4. 关键规则

| 规则 | 说明 |
|------|------|
| **超额限制** | 标注员领取量不超过「单人最大领取数量」 |
| **已提交保护** | 回收/取消分配不影响已提交的标注 |
| **独立池** | 每个任务的分配池独立管理 |

---

## 5. 常见问题

### Q1: 标注员看不到已发布的任务？

检查：任务是否已发布、标注员是否有权限、分配策略是否匹配。

### Q2: 如何将指定标注员的任务转移给另一个人？

先回收原标注员的未完成任务，再分配新标注员。

### Q3: 分配后还能增加数据量吗？

任务发布后不可增删数据。如需增加，需创建新任务。
