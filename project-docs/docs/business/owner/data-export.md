# 07 — 数据导出

> **所属角色**：任务负责人（Owner）  
> **入口路由**：`/owner/exports`  
> **关联操作**：[06-数据验收](./data-acceptance)

---

## 1. 场景概述

数据导出将验收通过的标注结果导出为结构化文件，用于模型训练、评测分析等下游任务。

---

## 2. 操作步骤

### 步骤 1：选择导出任务

在导出列表中选择要导出的任务/数据集。

### 步骤 2：配置导出参数

![数据导出演示](/img/demo/screenshots/Owner_数据导出.png)

![数据导出](/img/owner/owner-exports.png)

| 配置项 | 选项 | 说明 |
|--------|------|------|
| **导出格式** | JSON / CSV / JSONL | 结构化数据格式 |
| **数据范围** | 全部 / 已验收 / 按时间 | 导出数据筛选 |
| **字段选择** | 按需勾选 | 只导出需要的字段 |
| **导出模式** | 全量 / 增量 | 增量仅导出自上次导出后新增 |

### 步骤 3：提交导出

点击提交后，导出任务进入**异步队列**，可在「异步任务」页面查看进度。

### 步骤 4：下载数据

导出完成后，在导出列表中点击「下载」获取数据文件。

---

## 3. 支持格式

| 格式 | 特点 | 适用场景 |
|------|------|----------|
| **JSON** | 完整结构，保留嵌套关系 | 程序化处理 |
| **CSV** | 表格形式，可电子表格打开 | 数据分析、人工检查 |
| **JSONL** | 每行一条 JSON，流式处理 | 大文件分批处理 |
