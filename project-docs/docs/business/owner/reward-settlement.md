# 08 — 奖励结算

> **所属角色**：任务负责人（Owner）  
> **入口路由**：`/owner/settlements`  
> **关联操作**：[06-数据验收](./data-acceptance)

---

## 1. 场景概述

奖励结算管理标注员标注报酬的发放。基于验收通过的标注数据，按配置的奖励规则自动计算报酬。

---

## 2. 页面功能

![奖励结算演示](/img/demo/screenshots/Owner_奖励结算.png)

![奖励结算](/img/owner/owner-settlements-clean.png)

| 功能 | 说明 |
|------|------|
| **结算查询** | 按标注员、时间段、任务筛选 |
| **批量结算** | 对已验收的标注批量发起结算 |
| **结算记录** | 历史结算明细 |
| **导出报表** | 导出结算报表 |

---

## 3. 奖励规则类型

| 规则类型 | 计奖方式 | 适用场景 |
|----------|----------|----------|
| **按通过条数计奖** | 每条通过的标注固定单价 | 标准化标注任务 |
| **质量阶梯** | 根据审核通过率调整单价 | 质量控制要求高的任务 |
| **加急奖励** | 提前完成额外奖励 | 有时限要求的任务 |

---

## 4. 结算流程

```
验收通过 → 发起结算 → 系统计算 → 生成明细 → 导出报表
                                       ↓
                                 发放报酬（线下或对接支付）
```

---

## 5. 常见问题

### Q1: 结算周期多长？

结算不设固定周期，Owner 可根据需要随时发起批量结算。

### Q2: 结算数据如何核对？

在「结算记录」中查看每条计算的明细，支持导出 CSV 报表进行外部核对。
