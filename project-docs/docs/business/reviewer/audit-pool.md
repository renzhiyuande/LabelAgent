# 02 — 人工审核池

> **所属角色**：审核员（Reviewer）  
> **入口路由**：`/reviewer/audit-pool`  
> **关联操作**：[01 — AI 预审队列](./ai-queue)、[03 — 审核结果](./review-results)

---

## 1. 场景概述

人工审核池是审核员逐条审核标注结果的核心工作台。通过 AI 预审但需人工确认，或直接跳过 AI 预审进入人工流程的标注均在此处理。

## 3. 操作步骤

### 步骤 1：进入审核池

**操作路径**：侧边栏 → 「审核工作台」→「人工审核池」

或直接访问 `/reviewer/audit-pool`

### 步骤 2：查看标注内容

| 审阅项 | 说明 |
|--------|------|
| **题面信息** | 题目原文、模型回答 A/B |
| **标注结论** | 偏好结论（A 更优 / B 更优 / 平局） |
| **优势程度** | 标注员选择的优势程度 |
| **判断依据维度** | 勾选的评估维度 |
| **判断理由** | 详细理由 |
| **AI 评分** | AI 维度评分与置信度 |

### 步骤 3：执行审核操作

| 操作 | 说明 | 快捷键 |
|------|------|--------|
| **通过** | 标注通过审核 | `A` |
| **打回** | 退回标注员修改（需填写意见） | `R` |
| **修改** | 直接修改标注内容后通过 | `Ctrl+Enter` |

### 步骤 4：填写审核意见

- **通过**：可选填写备注
- **打回**：必须填写打回意见
- **修改**：在表单上编辑后提交

### 步骤 5：提交并切换下一条

点击「提交审核结论」或 `Ctrl + Enter`，自动加载下一条待审核标注。

## 4. 操作流程图

```
进入人工审核池
    │
    ├── 选择待审核标注
    │
    ├── 审阅题面 + 标注 + AI 辅助
    │
    └── 审核操作
         ├── 通过 ──→ 下一级审核或完成
         ├── 打回 ──→ 标注员修改后重新提交
         └── 修改 ──→ 微调后通过
```

---

## 5. 关键规则与约束

| 规则 | 说明 |
|------|------|
| **打回必填意见** | 打回时必须说明修改要求 |
| **多级审核** | 一级通过后自动进入二级队列 |
| **审核配置** | 由 Owner 在模板搭建器中设置 |
| **修改即通过** | 「修改」操作会直接以修改后内容通过 |

### 5.1 操作对比

| 操作 | 标注状态 | 标注员操作 | 适用场景 |
|------|----------|-----------|----------|
| **通过** | 审核通过 | 无需操作 | 标注准确无误 |
| **打回** | 需修改 | 重新作答 | 明显错误或不完整 |
| **修改** | 审核通过 | 无需操作 | 基本正确，只需微调 |

---

## 6. 常见问题

### Q1: 打回意见有什么要求？

应具体指明问题，如：偏好结论与理由不一致、维度选择不完整、缺乏对比分析等。

### Q2: 如何查看审核配置？

审核配置由 Owner 在模板搭建器中设置，右侧面板可查看当前 Prompt 与配置。

### Q3: 多级审核怎么处理？

一级审核通过后自动进入二级审核队列，队列中可见当前审核级别。
