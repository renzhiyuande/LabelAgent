# 03 — 审核结果

> **所属角色**：审核员（Reviewer）  
> **入口路由**：`/reviewer/review-results`  
> **关联操作**：[01 — AI 预审队列](./ai-queue)、[02 — 人工审核池](./audit-pool)

---

## 1. 场景概述

审核结果页面提供审核记录的查询、统计与导出。审核员可查看所有审核操作的完整历史，包括 AI 预审结论与人工审核意见。

## 2. 操作步骤

### 步骤 1：进入页面

**操作路径**：侧边栏 → 「审核工作台」→「审核结果」

或直接访问 `/reviewer/review-results`

### 步骤 2：筛选查询

| 筛选条件 | 说明 |
|----------|------|
| 时间范围 | 按提交或审核时间筛选 |
| 审核人 | 按审核员筛选 |
| 标注员 | 按标注员筛选 |
| 审核结果 | 通过 / 打回 / 修改 |
| 任务/模板 | 按任务名称或模板筛选 |

### 步骤 3：查看统计概览

| 统计项 | 说明 |
|--------|------|
| 审核总数 | 审核的标注总条数 |
| 通过率 | 审核通过的比例 |
| 平均审核耗时 | 每条标注的平均审核时间 |
| 打回率 | 打回标注的比例 |

### 步骤 4：查看审核详情

点击列表记录查看完整详情：

| 信息 | 说明 |
|------|------|
| 标注内容 | 标注员完整作答表单 |
| AI 预审结果 | AI 预审结论（如有） |
| 审核结论 | 审核员最终结果 |
| 审核意见 | 备注或打回意见 |
| 操作时间线 | 提交 → AI 预审 → 审核 |

---

## 3. 操作流程图

```
进入审核结果
    │
    ├── 设置筛选条件
    │
    ├── 查看统计概览（通过率、打回率等）
    │
    └── 点击详情 ──→ 完整审核记录与时间线
```

---

## 4. 关键规则与约束

| 规则 | 说明 |
|------|------|
| **结论不可改** | 审核结论提交后通常不可撤回 |
| **导出 CSV** | 右上角「导出」可下载列表 |
| **统计口径** | 通过率 = 通过数 / 审核总数 |

---

## 5. 常见问题

### Q1: 审核结果可以导出吗？

支持。通过右上角「导出」按钮下载 CSV 文件。

### Q2: 为什么看不到某些审核记录？

检查筛选条件是否过窄（时间范围、审核人、结果类型等）。

### Q3: 如何查看某个标注员的审核历史？

在筛选条件中选择「标注员」并输入名称即可。
