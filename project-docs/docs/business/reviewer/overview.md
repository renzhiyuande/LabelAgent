## 1. 角色概览

审核员（Reviewer）负责对标注员提交的结果进行质量审核，支持 **AI 预审队列** 与 **人工审核池** 两种模式，结合 AI 辅助与人工判断确保标注质量。

### 1.1 核心流程

```
标注提交
    │
    ▼
AI 预审 ──→ 高置信度通过（自动通过）
    │
    └──→ 进入人工审核池
              │
         ┌────┴────┐
         │         │
       通过       打回
         │         │
    审核完成    标注员修改
         │         │
         │    重新提交
         │         │
         └────┬────┘
              │
          再次审核
```

## 4. 常见问题

### Q1: AI 预审和人工审核有什么区别？

AI 预审适合高置信度场景的快速处理；人工审核逐条审阅，适用于需专业判断的复杂场景。

### Q2: 打回标注后会发生什么？

状态变为「需修改」，标注员可重新编辑并再次提交，修改后会再次进入审核流程。

### Q3: 如何批量审核？

在 AI 待审队列中，勾选多个审核项后使用「批量通过」或「批量打回」。

### Q4: 审核结果可以撤回吗？

通常审核结论提交后不可撤回。如需调整，请联系管理员处理。
